วิธีใช้
- แตก zip ให้ครบก่อน (ห้ามเปิดจากในไฟล์ zip โดยตรง)
- เปิด index.html ได้เลย โดยต้องมีโฟลเดอร์ images อยู่ข้างไฟล์ index.html
- หรือรัน  node server.js  แล้วเปิด http://localhost:3000
- อัปโหลดทั้งโฟลเดอร์ (index.html + images) ขึ้นโฮสต์สถิตใดก็ได้

เพิ่ม/แก้การ์ด: ใส่รูป .webp ใน images/thumb และ images/full แล้วเพิ่มแถวในตัวแปร CARDS ภายใน index.html
