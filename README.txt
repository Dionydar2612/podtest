วิธีใช้
- แตก zip ให้ครบก่อน (ห้ามเปิดจากในไฟล์ zip โดยตรง)
- เปิด index.html ได้เลย โดยต้องมีโฟลเดอร์ images อยู่ข้างไฟล์ index.html
  หน้า "การ์ดทั้งหมด" = index.html   หน้า "สร้างเด็ค" = index.html#deck
- หรือรัน  node server.js  แล้วเปิด http://localhost:3000
- อัปโหลดทั้งโฟลเดอร์ (index.html + images) ขึ้นโฮสต์สถิตใดก็ได้ เช่น Vercel

แก้กติกาเด็ค: ใน index.html ค้นหา  const CFG={MAIN:50,COPIES:4,REWARD_MAX:5}
  MAIN = จำนวนใบ Main Deck, COPIES = ใส่ซ้ำรหัสเดียวกันได้กี่ใบ, REWARD_MAX = การ์ดรางวัลสูงสุด
แก้ข้อมูล/ข้อความการ์ด: ตัวแปร CARDS ใน index.html

บันทึกเด็คเป็นภาพ/PDF: ต้องเปิดผ่านเว็บ (node server.js หรืออัปโหลดขึ้นโฮสต์) เบราว์เซอร์จะไม่ให้บันทึกภาพเมื่อดับเบิลคลิกเปิดไฟล์ตรง ๆ
รหัสเด็ครูปแบบ POD2:ชื่อ:รหัสการ์ด.จำนวน,...  (รหัสเก่า POD1 ยังนำเข้าได้)
